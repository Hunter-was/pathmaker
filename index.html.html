how it works

New Path

Every bubble has two fields: Do is the action for that step, Ask is the question that decides where to go next. Each bubble also has two answers — edit their labels, they default to Yes/No.

Sage-green lines are the first answer's path. Copper lines are the second answer's path — the color stays consistent all the way down the tree.

Click a dashed "+ add branch" box on the sides to grow the tree in that direction. The canvas scrolls down automatically as you build.

Ending a branch

Click End path here on any bubble to mark it as a stopping point. It's reversible — anything you've already built underneath is kept and comes right back if you toggle it off again.

Import Path

Drop a .yml file or paste its contents, then load it straight into the editor to keep building or fix it up.

Run Path

Load a path the same way as Import, then work through it step by step: the left panel shows what to do first, then what to ask, with buttons for each answer. The right panel shows the whole tree with your current step highlighted, scrolling to keep it in view. Use Previous or Restart any time.

Saving your work

Name your path at the top of the editor, then hit Export .yml to download it — plain text, easy to read or hand-edit, and ready to drop back in later.
